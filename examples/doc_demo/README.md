# geo

Small 2D geometry primitives — the example library of SafeC's
`safeguard doc` and `safeguard publish`. Start with [Point] and
[shape_area].

```sh
safeguard test           # builds the library and runs tests/
safeguard doc --serve    # its API reference at http://localhost:8000/
safeguard publish        # what publishing it would set up (a dry run)
```
